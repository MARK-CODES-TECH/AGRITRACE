Setup Options

Option 1: Instant Test Access ⚡

  1. Go to: http://localhost/AG/test-login.php
  2. Click on any role button (Farmer, Admin, Official)
  3. Your panel opens instantly with a test session

Option 2: Production Login

  1. Go to: http://localhost/AG/
  2. Click "Login" or visit http://localhost/AG/login.php
  3. Enter your credentials
  4. Access your dashboard and panels

Option 3: Direct URLs

http://localhost/AG/farmer.php (Farmer Panel) http://localhost/AG/admin.php (Admin Panel) http://localhost/AG/agriDA.php (Official Panel)
Note: Requires active login session

Troubleshooting

Page not loading?
• Make sure XAMPP Apache & MySQL are running
• Check if the URL is correct: http://localhost/AG/
• Try refreshing (Ctrl+F5) or clearing cache
Getting "Database Connection Failed"?
• Ensure MySQL is running in XAMPP Control Panel
• Verify database name is "myproject4"
• Check db_connect.php credentials
Session Issues?
• Clear browser cookies for localhost
• Try an incognito/private browser window
• Restart XAMPP if needed
